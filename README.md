# Employee Attendance

A simple employee attendance web application built as a practical learning project for human-governed Agentic Engineering.

## Project Goal

The project is intended to:

* build a working employee attendance MVP;
* practice end-to-end application development;
* learn how to coordinate coding agents through controlled stages;
* maintain a small, understandable, and portfolio-ready codebase.

## MVP Status

Current stage:

**Stage 5B — Authentication & Authorization Implementation**

Authentication and authorization foundation is in place. Product features have not been implemented yet.

## Local Development Login

After running the development seed, these non-production demo accounts are available:

* Admin: `admin@example.test` / `admin-password`
* Employee: `employee.login@example.test` / `employee-password`

## Planned MVP

The first release will support:

### Admin

* Admin login
* Employee listing
* Add and edit employees
* Attendance history
* Simple attendance summary

### Employee

* Employee login
* Check-in
* Check-out
* Today's attendance status
* Personal attendance history

## Initial Technology Direction

The initial technology direction is:

* Next.js
* TypeScript
* PostgreSQL
* Tailwind CSS
* pnpm

The ORM, authentication provider, database provider, and deployment platform will be selected during the architecture stage.

## Engineering Principles

* MVP-first
* Small and validated changes
* No unnecessary features
* No premature architecture
* No implementation without repository evidence
* Every implementation stage ends with validation and a controlled Git checkpoint
